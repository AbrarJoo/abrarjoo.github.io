## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/AbrarJoo/abrarjoo.github.io.git
```

Navigate into the project:

```bash
cd abrarjoo.github.io
```

Then open `index.html` in your browser.

For development, you can use the **Live Server** extension in VS Code.

## 🌍 Deployment

Every update to the repository can be deployed to the live portfolio through the GitHub Pages workflow.
